# Appendix

The appendix holds six supporting analyses for the report on mosaic variegated aneuploidy caused by variants in *BUB1B*, the gene for BubR1 (a spindle-checkpoint protein). The table gives one line on each.

| Item | Content |
|---|---|
| [Probability of an error-free division](error-free-division.md) | A model estimate of about 0.93, its inputs, sensitivity and checks |
| [Pathogenicity prediction for the missense variant](variant-pathogenicity-prediction.md) | AlphaMissense score of 0.92 and its calibration against measured alleles |
| [Cell-cycle map](cell-cycle-map.md) | Cyclins, cyclin-dependent kinases (CDKs) and the anaphase-promoting complex/cyclosome (APC/C), with excluded drug classes |
| [Residue atlas](residue-atlas.md) | BubR1 structure and ligand census, dose anchors and a ranking of restoration designs |
| [Removal or replacement of aneuploid cells](aneuploid-cell-removal.md) | Detection arithmetic and dosage-correction tools from trisomy 21 research |
| [Alternative approaches assessed](alternative-approaches-assessed/README.md) | Ten alternative approaches and the evidence against each |
